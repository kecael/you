安全提示：密钥仅限本机演示

下面的翻译 / 语音 API 密钥目前只保存在本浏览器的 localStorage 中，并直接由浏览器发起请求。 这种方式仅适合本机调试，不适合正式上线。

  • 正式部署时，密钥应由后端保管，由后端转发请求，前端不接触密钥。
  • 本机调试完成后，建议在浏览器设置中清除本站数据，避免密钥残留。
  • 不要在公共电脑或共享浏览器中填入真实密钥。
