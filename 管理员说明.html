管理员说明

面向课程维护者，不是学习者文档

内部文档 · 请勿公开分享

1. 管理后台入口与口令

管理后台地址：admin.html（不在学习站主导航中，只能从页面页脚的「管理员入口」进入）。

  • 默认口令：linguaview-admin（在 admin.html 的 ADMIN_KEY 常量中修改）。
  • 登录状态只保存在当前浏览器会话（sessionStorage），关闭浏览器即失效。

重要：这是前端口令，只用于挡住普通访客，不能替代真正的权限控制。正式上线前必须改为后端登录鉴权。

2. 本地启动网站与后端

只看学习内容：直接双击任意 HTML 文件即可打开，无需服务器。

需要上传视频 / 调用翻译：请启动本地服务：

  1. 双击 启动.bat（会拉起后端并显示访问地址）。
  2. 在浏览器打开 http://localhost:8090。
  3. 后端接口位于 api/main.py（FastAPI + SQLite），默认端口 8000。

依赖清单见 api/requirements.txt。

3. 上传课程内容

  • 视频支持：.mp4 / .mov / .avi / .webm / .mkv，建议单个不超过 500MB。
  • 字幕支持：.srt / .vtt，中英混排时按「一行英文 / 一行中文」编写，导入时会自动识别分离。
  • 上传后可逐句校对英文与中文，并补充重点词、音标、例句。
  • 只有当课程同时具备可播放视频与字幕时，才应在前台对外展示；仅字幕的内容应标注为「示例课程」。

4. API 密钥安全（务必阅读）

当前翻译与语音识别密钥的存放方式只适合本机调试：

  • 密钥由管理员在前台填写，保存在浏览器 localStorage 中（linguaview_baidu_config、linguaview_speech_config）。
  • 请求由浏览器直接发往百度接口（部分经公共代理转发）。

正式部署必须整改：密钥放在后端环境变量中，由后端签名并转发请求，前端不得接触 Secret Key；同时关闭公共代理。

本机调试结束后，建议在浏览器设置中清除本站数据，避免密钥残留。

5. 数据存储现状

  • 上传的课程保存在浏览器 localStorage（linguaview_videos），不跨设备、不跨浏览器，清除站点数据即丢失。
  • 大视频文件保存在浏览器 IndexedDB（PersistentVideo），同样仅限本机。
  • 后端数据库为本地 SQLite（linguaview.db），仅本机可访问。

因此当前版本不能作为多人协作的内容管理平台；如需正式运营，应把内容迁移到服务端数据库并配对象存储。

6. 正式上线前检查清单

  • 为每节课程提供可播放视频 + 双语字幕 + 明确来源。
  • 移除或标注所有演示用数据，不显示虚构的播放量、观看数、课程数量。
  • 管理后台改为后端登录鉴权，隐藏或移除前端口令。
  • 翻译 / 语音密钥迁到后端，前端不再保存 Secret Key。
  • 账号体系与云端学习进度（当前仅有本机计数）。
  • 字体、图标等静态资源本地化，避免依赖境外 CDN。
  • 补齐隐私政策、版权与素材授权说明。

7. 版权与素材要求

  • 视频、字幕、影视片段等素材必须确认可商用或已获授权，并在课程信息中标注来源。
  • 禁止直接使用未授权的影视剧片段作为课程素材。
  • 用户上传或生成的内容需确认不侵犯第三方权利。
