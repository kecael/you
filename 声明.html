三、隐私说明

1. 网站当前不收集账号信息

本站目前没有注册与登录功能，不会收集你的姓名、手机号、邮箱等个人身份信息，也没有用户画像或广告追踪。

2. 数据保存在你自己的浏览器里

  • 你上传的课程与视频，保存在当前浏览器的 localStorage 与 IndexedDB 中。
  • 这些数据只存在你的设备上，不会上传到本站服务器，也不会同步到其他设备。
  • 清除浏览器站点数据后，这些内容会一并删除且无法恢复。

3. 麦克风与录音

只有在你主动使用管理后台的「语音识别 / 麦克风识别」功能时，浏览器才会请求麦克风权限。录音仅用于当场生成字幕，不会由本站长期保存；是否留存取决于你所使用的第三方语音服务。

4. 第三方服务的数据传输

当你（管理员）使用翻译或语音识别功能时，相关文本或音频会被发送到你配置的第三方服务（如百度翻译 / 百度语音识别）进行处理。这些服务的数据处理规则以其各自的隐私政策为准。本站当前不参与、也无法控制该等第三方的数据处理。

5. 如何清除你的数据

  • 在浏览器设置中找到「清除浏览数据 / 网站数据」，选择本站域名后清除。
  • 或在开发者工具中清空 localStorage 与 IndexedDB。
